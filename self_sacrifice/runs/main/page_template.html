Prompts

Exact text sent to Gemma-4-31B. Pick a wording and a history. The example uses one name set and one role assignment. Highlighted lines differ from the "none" history.

The two versions

  • main: the model writes its own first reply, then gets the final message.
  • main-fixed-first-response: the first reply is always $ pass, then it gets the same final message.

How the prompts are paraphrased

Only the system prompt is reworded, into four wordings, P0 to P3. Each states the same ten parts, shown below for one example agent. The round messages are the same in every wording. P2 is written as flowing paragraphs at a different facility, and P3 as a numbered list. Each wording also runs with six name sets, eight role assignments and four histories: 768 conversations per version.
